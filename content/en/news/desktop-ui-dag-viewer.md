title: "Desktop UI: DAG viewer, runner management, and job status"
date: 2026-07-22
summary: "The Electron desktop app gains a dependency-graph viewer, DITE runner management, live job status, and an integrated terminal."
---

The Celebi desktop application (Electron) received a major update:

- **DAG viewer** — visualize the dependency graph of tasks, algorithms, and data in the project.
- **DITE runner management** — configure and monitor execution backends from the UI.
- **Job status display** — follow running and finished tasks at a glance.
- **Integrated terminal** — run Celebi commands without leaving the app.
- Task metadata inspection, impression results view, and README editing round out the workbench.
