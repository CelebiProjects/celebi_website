title: "Celebi skills for Claude Code released"
date: 2026-03-03
summary: "A skill collection that lets Claude Code navigate Celebi projects, create objects, and run workflows autonomously."
---

`celebi-skills` is a collection of [Claude Code](https://claude.com/claude-code) skills for AI-assisted analysis with Celebi. It includes skills for:

- Navigating project structure (`tree`, `ls`)
- Creating tasks and algorithms
- Submitting and monitoring workflows
- Debugging and amending existing components
- Checking logs and retrieving outputs

Install them with:

```sh
npx skills add CelebiProjects/celebi-skills --skill '*' -g -y
```
