title: "VS Code extension: styled output and README rendering"
date: 2026-05-02
summary: "The VS Code extension adds a Celebi output formatter for ls/trace/message views and a Markdown README webview."
---

The Celebi VS Code extension keeps improving the in-editor experience:

- **Output formatter** — `ls`, `trace`, and message panels render as styled HTML instead of plain text.
- **README webview** — object documentation renders as Markdown in a dedicated panel.
- Dynamic project tree, task submission, impression dialogs, project switching, and DAG trace visualization are all available from the Activity Bar.

The extension auto-detects your Python virtualenv and Celebi project layout on open.
