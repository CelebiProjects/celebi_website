## CelebiChrono

The initial beta release of CelebiChrono: the Celebi analysis model.

- **Projects, tasks and algorithms** as folders on disk, managed from the Celebi
  shell (`celebi use`, `create-task`, `add-algorithm`, `add-input`, ...).
- **Impressions**: every state of an object is an impression with a
  deterministic UUID, so results are reproducible and addressable.
- **Workflow orchestration**: tasks reference algorithms and data through
  dependency arcs; `impress` and `submit` drive the Gen → Fit pipeline.
- **Status and collection**: `status` tracks submissions; `collect` pulls
  outputs back from the server.

## Yuki (DITE server)

The first release of the Yuki server behind DITE.

- **Storage**: projects, impressions, workflow runs and stageout files under
  `~/.Yuki/Storage`.
- **Execution**: workflows run on REANA; native/local execution with status
  propagation.
- **HTTP API**: upload, execute, status, collect and output endpoints consumed
  by CelebiChrono.
