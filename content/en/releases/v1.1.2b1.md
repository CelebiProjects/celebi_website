## EOS accounting and cleanup

CelebiChrono and Yuki both move to `1.1.2b1`. `eos-usage` reports managed EOS cache
by project as live, non-live or unknown. Measurements run inside small REANA jobs;
no EOS mount is required on the client or Yuki host. Incomplete scans and ambiguous
legacy-directory ownership are reported explicitly.

```sh
celebi-cli eos-usage cern --all-projects
celebi-cli eos-cleanup cern --all-projects --include-unknown
celebi-cli eos-cleanup --plan-id PLAN_ID --execute
```

Cleanup defaults to preview, preserves live data, and binds execution to the
reviewed manifest. `--clear-project UUID` explicitly includes that project's live
cache. Unknown data requires `--include-unknown`; unattributed directories are
skipped. Recent complete scans, live sets and file metadata are checked again.
Active project workflows block submission. An independent read-only job verifies
deletion; partial or uncertain operations are never blindly retried. `tidyup`
provides an interactive entry. See the [EOS guide](/guide/eos-cache/).

## Celebi fixes

Submission now passes `cache_on_runner` preferences for the dependency graph,
including tasks outside the directly selected scope. Generated `__pycache__`,
`.pyc` and `.pyo` files are excluded from impression tree comparison, content
hashing and file diffs, including historical entries.

## Yuki native previews

This beta includes the native `/remote-export` fix prepared in `1.1.1b1`: read
nested stageout files without prior collection, with MIME, HEAD and byte-range
support and protection against escaping paths/symlinks. SSH/IHEP streaming is
retained. Previewing does not archive a result into Yuki Storage.

## Upgrade

Update both Python components and reload Yuki's HTTP service for the new routes.
Old EOS scans without metadata fingerprints must be replaced before cleanup.
The [VS Code extension](/guide/3_celebi_extension_vscode/) remains a separately
versioned package; its Remote SSH preview and UI updates are not installed by a
Python package upgrade. This is a beta source update, not a claim of publication
to PyPI or Marketplace.
