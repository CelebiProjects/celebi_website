## Repeated Task execution

Tasks can now declare `subtasks: N` to run one frozen definition for indices
`0..N-1` while retaining one Task impression and one Yuki job. `${index}` selects
partitioned inputs; each execution writes through literal `stageout/index/`, and
caches, collection, and downstream aliases preserve `stageout/<number>/`.
Per-instance logs use `log COMMAND --subtask N`. Terminal details retain failed
indices and short failures are classified from backend execution evidence.

The bilingual guide includes a complete generate → 100 Gaussian fits → summary
example and documents cache and retry limitations. Yuki now expands nested REANA
listings and archive downloads without flattening repeated outputs.

## Environments and LHCb releases

New projects include a project-scoped Conda environment template. Yuki resolves
logical names to runner prefixes isolated by project UUID on native, SSH, and IHEP
runners. Algorithms and Tasks can declare fixed or nightly `lb_run` releases with
parameter substitution. Dated `lb-conda/PACKAGE/DATE` remains a separate reserved
environment and cannot be combined with `lb_run`.

## Impression sharing and APD credentials

`share-ssh-impressions --export/--import RUNNER` moves complete immutable active
Task snapshots through an SSH runner's managed store. It is separate from selected
stageout transfer and supports Task, directory, or project scopes. Deposited
`config.local.json` and staged `lbapi_key.json` credentials are excluded in both
directions; the destination supplies its own local credential when needed.

`add-apd-token` now supports ordinary and repeated execution Tasks, including
LbConda Tasks. Celebi keeps the token in git-excluded local configuration and
refreshes it on resubmission; Yuki stages a mode-`0600` token file without placing
the value in generated commands or logs.

## Reliability fixes

- SSH cached-input Snakefiles safely encode quotes, backslashes, and literal braces
  used by `find -exec`.
- REANA cleanup traps coexist with subtask status recording.
- Nested result downloads write completion markers only after selected files are
  stored successfully.
- The development Compose setup correctly loads an optional bind-mounted Celebi
  checkout.

CelebiChrono and Yuki are released together as version `1.1.0`.
