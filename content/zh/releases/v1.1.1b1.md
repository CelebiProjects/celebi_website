## Native 输出预览

Yuki `1.1.1b1` 为 `/remote-export` 补齐 native runner 支持。此前，结果列表中
可能已经显示文件，但预览返回 `NOTFOUND`，因为该接口只处理基于 SSH 的 runner。
现在可以直接读取 native workflow 的 `stageout`，包括
`stageout/2/plots/fit.png` 等重复任务路径，无需先复制到 Yuki Storage。

接口支持 MIME 类型识别、HEAD 请求和文件查看器使用的 HTTP 字节范围请求，阻止
路径越界及指向 stageout 外部的符号链接，并保留 SSH/IHEP 流式读取行为。
相关路由测试共 17 项，全部通过。

## Remote SSH 预览

配套的 VS Code 扩展修复让图片、PDF 和文本预览经过扩展端代理与 VS Code 转发
地址，使本机 Webview 能访问远程服务器上的 Yuki。图片放大使用相同地址；图片
加载失败时会显示提示。

要通过 Remote SSH 直接预览 native 输出，需要同时更新 Yuki 服务端代码并重新
加载 HTTP 服务，以及安装包含转发修复的扩展构建。操作说明见
[VS Code 指南](/zh/guide/3_celebi_vscode_extension/)。

## 预发布状态

这是 Yuki 的 beta 补丁，CelebiChrono 仍为 `1.1.0`。源码版本和更新说明已准备好；
本次网站更新不表示已发布到 PyPI 或 Marketplace。目标 Remote SSH 环境的现场
验证仍待完成。预览不会自动收集或归档文件；需要在 Yuki Storage 保留副本时，
仍应使用 `collect`。
