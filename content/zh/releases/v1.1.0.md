## 重复 Task 执行

Task 现在可以声明 `subtasks: N`，用同一份冻结定义执行 `0..N-1`，同时仍只保留
一个 Task impression 和一个 Yuki job。`${index}` 选择分区输入；每个实例通过固定
路径 `stageout/index/` 写出，缓存、收集和下游 alias 则保留
`stageout/<编号>/`。实例日志使用 `log COMMAND --subtask N`。终态详情会保留失败
编号，并根据后端执行证据识别轮询间发生的短任务失败。

双语指南新增完整的“生成 → 100 次高斯拟合 → 汇总”示例，并说明缓存与重试限制。
Yuki 现在会展开 REANA 的嵌套列表和归档下载，不会压平重复任务输出。

## 环境与 LHCb release

新项目包含项目专属 Conda 环境模板。Yuki 在 native、SSH 和 IHEP runner 上把逻辑
环境名解析为按项目 UUID 隔离的 prefix。Algorithm 和 Task 可声明固定或 nightly
`lb_run` release，并使用参数替换。指定日期的 `lb-conda/PACKAGE/DATE` 是独立的
保留环境形式，不能与 `lb_run` 同时使用。

## Impression 分享与 APD 凭据

`share-ssh-impressions --export/--import RUNNER` 通过 SSH runner 受管区移动完整、
不可变的 active Task 快照。它不同于选择性 stageout 迁移，支持 Task、目录或项目
范围。双向分享都会排除已 deposit 的 `config.local.json` 和暂存的
`lbapi_key.json`；目标环境需要时自行提供本地凭据。

`add-apd-token` 现在也支持普通和重复执行 Task，包括 LbConda Task。Celebi 把
token 保存在 Git 排除的本地配置中，并在重提时刷新；Yuki 只暂存权限为 `0600` 的
token 文件，不把值写入生成命令或日志。

## 可靠性修复

- SSH 缓存输入生成的 Snakefile 会正确编码引号、反斜线和 `find -exec` 使用的字面
  花括号。
- REANA 清理 trap 与 subtask 状态记录可以同时生效。
- 嵌套结果下载只有在所选文件全部保存成功后才写完成标记。
- 开发 Compose 配置能正确加载可选的 Celebi bind mount。

CelebiChrono 与 Yuki 共同发布为 `1.1.0`。
