## EOS 统计与清理

CelebiChrono 和 Yuki 统一更新为 `1.1.2b1`。`eos-usage` 按项目统计托管 EOS
缓存，区分 live、non-live 和 unknown。扫描在 REANA 小作业中完成，客户端和
Yuki 主机无需挂载 EOS；报告会说明不完整测量和旧式目录归属不明的情况。

```sh
celebi-cli eos-usage cern --all-projects
celebi-cli eos-cleanup cern --all-projects --include-unknown
celebi-cli eos-cleanup --plan-id PLAN_ID --execute
```

清理默认只生成预览并保护 live 数据，执行绑定到确认过的清单。
`--clear-project UUID` 显式包含该项目的 live 缓存；unknown 需要
`--include-unknown`，无法确定项目归属的目录仍跳过。执行前复核近期完整扫描、
live 信息和文件元数据，项目存在运行中或排队中的 workflow 时拒绝提交。
删除后另交只读作业复查；部分完成或提交结果不确定时不会盲目重试。
`tidyup` 提供交互入口。详见 [EOS 使用指南](/zh/guide/eos-cache/)。

## Celebi 修复

提交项目或所选任务时，`cache_on_runner` 设置会覆盖完整依赖图，而不再仅包含
直接选择的任务。Impression 树比较、内容哈希和文件差异排除 `__pycache__`、
`.pyc`、`.pyo`，也兼容历史记录中的这些条目，避免生成字节码导致误判变化。

## Yuki native 预览

本版本包含先前为 `1.1.1b1` 准备的 native `/remote-export` 修复：无需 collect
即可读取嵌套 stageout 文件，支持 MIME、HEAD、HTTP Range，并阻止路径或符号
链接越界；SSH/IHEP 流式读取保留。预览不等于把结果归档到 Yuki Storage。

## 升级说明

同时更新两个 Python 包，并重载 Yuki HTTP 服务以启用新接口。缺少元数据指纹的
旧 EOS 扫描不能直接用于清理，需要重新扫描。
[VS Code 插件](/zh/guide/3_celebi_vscode_extension/) 独立版本管理；Remote SSH
预览修复及界面更新需要单独安装插件。本页记录 beta 源码更新，不表示已经发布
到 PyPI 或 Marketplace。
