Celebi VS Code 插件持续改进编辑器内体验:

- **输出格式化** —— `ls`、`trace` 与消息面板以带样式的 HTML 呈现,不再是纯文本。
- **README 渲染** —— 对象文档在独立面板中以 Markdown 渲染。
- 动态项目树、任务提交、impression 对话框、项目切换与 DAG trace 可视化,均可从活动栏直接使用。

插件在打开项目时会自动检测 Python 虚拟环境与 Celebi 项目结构。
