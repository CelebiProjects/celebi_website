Celebi 桌面应用(Electron)迎来重要更新:

- **DAG 查看器** —— 可视化项目中任务、算法与数据之间的依赖图。
- **DITE runner 管理** —— 在 UI 中配置并监控执行后端。
- **作业状态显示** —— 一目了然地跟踪运行中与已完成的任务。
- **内置终端** —— 无需离开应用即可执行 Celebi 命令。
- 此外还包括任务元数据查看、impression 结果视图与 README 编辑等功能。
