# 使用 Celebi VS Code 扩展

在前两篇教程中，我们学习了如何创建 Celebi 工作流、连接多个任务，以及在远程服务器上执行分析程序。

然而，仅使用命令行界面不太方便查看任务的详细信息和分析结果，尤其是当我们需要处理存储在远程服务器上的大型数据文件时。

为了解决这个问题，我们提供了 **Celebi VS Code 扩展**。它提供了一个图形化界面，可以方便地管理工作流、查看任务依赖关系、监控任务运行状态以及预览分析结果。

最重要的是，**我们可以直接在 VS Code 中预览中间结果，而不需要将完整的输出文件下载到本地计算机。**

## 1. 安装 Celebi 扩展

打开 VS Code，进入左侧的 **Extensions（扩展）** 面板，也可以使用快捷键 `Ctrl+Shift+X`。

搜索 `Celebi` 并安装扩展。

![Celebi 扩展](https://github.com/user-attachments/assets/e2fc41d0-8431-4c79-894f-d98539e29057)

安装完成后，VS Code 左侧活动栏中会出现 Celebi 图标。

## 2. Celebi 面板概览

点击 Celebi 图标，打开扩展面板。

![Celebi 面板](https://github.com/user-attachments/assets/87092320-57a8-47aa-a54f-c95f0400837f)

面板中会显示 Celebi 项目的目录结构，包括各个文件夹和任务。

你可以展开目录、选择不同的任务，从而方便地浏览整个分析工作流，而不需要手动查找对应的文件。

### 连接 Celebi

首先，确保已经按照第一篇教程中的步骤启动了 Yuki 和 Celebi。

然后点击 Celebi 面板右上角的 **Refresh（刷新）** 按钮。

成功连接后，DITE 状态将显示：

```text
DITE: connected
```

这表明 VS Code 扩展已经成功连接到 Celebi 服务。

## 3. 查看任务详情

在 Celebi 面板中选择一个任务，其详细信息就会显示在右侧。

![Celebi 任务详情](https://github.com/user-attachments/assets/4271ab4d-3d75-416b-96c2-d1b23b50c2fa)

任务详情包含以下几个部分。

### 3.1 README

`README.md` 用于描述任务的目的和功能。

**强烈建议为每个任务编写 README**，尤其是在包含大量处理步骤的复杂工作流中。

清晰的 README 可以帮助自己和其他合作者快速理解任务的作用，而不必逐一阅读源代码。

### 3.2 Job Status（任务状态）

**JOB STATUS** 部分显示任务的运行信息，包括：

- 当前任务的执行状态
- 请求使用的远程 Runner

通过这个面板，可以直接在 VS Code 中查看分析任务的运行情况。

### 3.3 Predecessors 和 Successors（前驱与后继任务）

**PREDECESSORS（前驱任务）** 显示当前任务依赖的上游任务，这些任务为当前任务提供输入数据。

**SUCCESSORS（后继任务）** 显示依赖当前任务输出的下游任务。

点击对应的导航图标，可以直接跳转到相关任务。

对于具有复杂依赖关系的**有向无环图（Directed Acyclic Graph, DAG）** 工作流，这一功能尤其有用。

### 3.4 Celebi 配置文件

**CELEBI.YAML** 部分允许查看和编辑任务的配置，包括：

- 执行命令
- Conda 环境
- 内存限制
- 其他任务设置

这样就不需要手动查找和打开对应的配置文件。

## 4. 预览分析结果

**RESULTS（结果）** 是 Celebi 扩展最重要的功能之一。

它允许我们直接浏览和预览远程服务器上的输出文件，而不需要手动将这些文件传输到本地。

### 4.1 预览 ROOT 文件

在 RESULTS 部分点击一个 ROOT 文件。

扩展会显示文件中的内容，例如 TTree 等对象。

![ROOT 文件浏览](https://github.com/user-attachments/assets/94bb3e92-7be2-43f1-9027-6461d243a442)

例如，点击 `DecayTree`，即可展开该 TTree 并查看其中的 branches（分支）。

选择一个变量后，稍等片刻，其分布就会显示在右侧预览面板中。

![ROOT 变量分布](https://github.com/user-attachments/assets/0a27ff88-1fe4-462d-b39d-de6af98b59fa)

这一功能非常适合快速检查：

- 运动学变量分布
- 不变质量谱
- 事例筛选结果
- 中间分析结果

**无需额外编写绘图程序，也不需要下载完整的 ROOT 文件，就可以直接检查变量分布。**

### 4.2 预览 PDF 文件

Celebi 扩展也支持预览 PDF 输出文件，例如拟合结果和各种诊断图。

在 RESULTS 部分点击 PDF 文件，即可显示其预览。

![PDF 文件预览](https://github.com/user-attachments/assets/3b7e3a0a-f3bc-4485-a352-13c5b92bc120)

如果希望查看更大的图像，可以直接点击预览图。

![放大 PDF 预览](https://github.com/user-attachments/assets/4d0f9294-335b-433e-a3b3-c0e94258d9fa)

这样就可以直接在 VS Code 中查看拟合结果、比较变量分布以及检查分析质量。

### 4.3 下载输出文件

如果需要在本地进一步处理某个输出文件，或者希望保留其副本，可以通过扩展提供的文件操作功能进行下载。

不过，对于大型中间数据文件，通常更推荐将其保留在远程服务器上，并尽可能使用预览功能进行检查。

## 5. 总结

Celebi VS Code 扩展为 Celebi 分析项目提供了方便的图形化管理界面。

其主要功能包括：

- **工作流导航：** 浏览项目目录、任务及其依赖关系。
- **任务管理：** 查看任务运行状态、配置文件和说明文档。
- **远程结果预览：** 无需下载完整数据集，即可浏览 ROOT 文件并绘制变量分布。
- **图像查看：** 直接在 VS Code 中预览 PDF 图像和分析结果。
- **按需下载：** 只在必要时下载输出文件。

结合 Celebi 命令行工具和 VS Code 扩展，我们可以更加高效地开发和管理复杂的物理分析工作流。

**通过 Celebi，我们只需要在本地管理和开发分析程序，将大型数据集和中间结果保留在远程服务器上，并且可以随时预览这些结果，从而避免不必要的文件传输和本地存储开销。**
